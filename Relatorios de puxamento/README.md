# Relatórios de puxamento
Cada pasta contida neste repositório contém o relatório do puxamento em si, as imagens de tal relatório, e quaisquer dados relevantes sobre o mesmo.
Os IDs (ex. PLT0000) são derivados de uma contagem crescente de fabricações na torre de puxamentos de polímeros (PLT significa Polymer Tower) do Laboratório de Fibras Especiais e sensores ópticos (LaFE).
